Мини-приложение для игроков гача-игр. Отвечает на главный вопрос каждого копильщика: **сколько валюты нужно зарабатывать в день, чтобы к нужной дате накопить нужное число круток?**

![Скриншот приложения](docs/screenshot.png)

Три игры в одном окне, у каждой — своя вкладка:

| Вкладка | 1 крутка | Крутки называются | Валюта |
|---|---|---|---|
| **Genshin Impact** | 160 | Переплетённые судьбы | примогемы |
| **Arknights: Endfield** | 500 | Chartered HH Permit | Oroberyl |
| **Neverness to Everness** | 160 | Solid Dice | Annulith |

## ✨ Возможности

- 🎮 **Три игры во вкладках** — Genshin Impact, Arknights: Endfield и Neverness to Everness; у каждой своя стоимость крутки, своя валюта и свой цвет интерфейса
- 💾 **Своя память у каждой вкладки** — дата, цель и накопления сохраняются в браузере и не сбрасываются при перезапуске
- 📅 **Дата цели** — с быстрыми пресетами: неделя, 2 недели, месяц, патч (42 дня), 3 месяца
- 🎯 **Цель в крутках** — пресеты под каждую игру (например, 180–1260 в Genshin Impact, 120–840 в Endfield)
- 💎 **Учёт текущих накоплений** — крутки и валюта, что уже есть
- 📊 **Сводка** — сколько не хватает, норма в день / неделю / месяц, прогресс-бар
- ⚠️ **Предупреждения** — дата прошла, дата сегодня, остался 1 день
- ⟲ **Сброс вкладки** — вернуть значения текущей игры к начальным
- 🌙 Тёмная тема, адаптивная вёрстка — удобно и с телефона

## 🚀 Запуск

Приложение — обычная статическая страница, ничего устанавливать не нужно:

1. скачайте репозиторий (`Code → Download ZIP` или `git clone`);
2. откройте `index.html` в браузере.

Либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 🧮 Как считается

Стоимость крутки зависит от игры: **160** примогемов в Genshin Impact, **500** Oroberyl в Arknights: Endfield, **160** Annulith в Neverness to Everness. Дальше — обозначим её `C`:

```
не хватает   = цель × C − (крутки × C + валюта)
норма в день = не хватает / дней до цели   (округление вверх)
```

Если дата цели — сегодня или уже прошла, расчёт всё равно показывается (как для 1 дня), плюс выводится предупреждение.

## 📁 Структура проекта

```
├── index.html              # разметка страницы: вкладки игр и форма
├── css/
│   └── styles.css          # стили: тёмная тема, карточки, цвета игр, адаптив
├── js/
│   ├── utils.js            # форматирование чисел, склонения, даты
│   ├── games.js            # каталог игр: стоимость крутки, валюта, пресеты
│   ├── store.js            # память вкладок (localStorage) с защитой от сбоев
│   ├── calc.js             # чистая логика расчёта (без DOM)
│   ├── render.js           # отрисовка результата в HTML
│   └── app.js              # точка входа: вкладки, состояние, обработчики
├── electron/
│   ├── main.js             # главная программа Electron-приложения (exe)
│   ├── icon.ico            # иконка приложения (Windows)
│   └── icon.png            # она же в PNG
├── tests/
│   ├── calc.test.js        # тесты логики расчёта (все три игры)
│   ├── games.test.js       # тесты каталога игр
│   ├── store.test.js       # тесты памяти вкладок
│   ├── utils.test.js       # тесты утилит
│   └── render.test.js      # тесты отрисовки
├── gacha-calc-3games.html  # однофайловый прототип (в сборки не входит)
├── docs/
│   ├── screenshot.png      # скриншот для README
│   └── release-notes.md    # текст для страницы релиза
└── .github/workflows/      # CI (тесты), Pages и сборка exe-релизов
```

Модули сознательно написаны как обычные скрипты (не ES-модули), чтобы страница работала даже при открытии по двойному клику через `file://`. При этом `utils.js`, `games.js`, `store.js`, `calc.js` и `render.js` экспортируют свой API и в CommonJS — поэтому они тестируются в Node без браузера и без зависимостей.

Чтобы добавить четвёртую игру, достаточно дописать её в `js/games.js` (стоимость крутки, название валюты, пресеты цели) и добавить кнопку-вкладку в `index.html` — расчёт, подписи и тема подхватятся сами.

## 🧪 Тесты

```bash
npm test        # или просто: node --test
```

Тесты покрывают логику расчёта по всем трём играм (округления, крайние случаи с датами), каталог игр, память вкладок, склонения и отрисовку. CI прогоняет их на Node 20 и 22 при каждом пуше и в pull request'ах.

## 🌐 GitHub Pages

После мержа в `main` сайт автоматически публикуется на GitHub Pages — workflow [`deploy.yml`](.github/workflows/deploy.yml). Чтобы это заработало, включите в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

## 🖥️ Десктоп-версия (exe)

Приложение оборачивается в [Electron](https://www.electronjs.org/) — интерфейс тот же, но в отдельном окне, без браузера. Сборка для Windows (установщик + портативный exe) происходит на GitHub Actions.

```bash
# локальный запуск десктоп-версии (нужен Node.js)
npm install
npm start

# локальная сборка exe (Windows)
npm run dist
```

### Как выпустить новую версию

1. поднимите `version` в `package.json` (например, `1.1.0`);
2. сделайте коммит и поставьте тег: `git tag v1.1.0 && git push origin v1.1.0`;
3. workflow [`release.yml`](.github/workflows/release.yml) сам соберёт exe и опубликует релиз с файлами на странице Releases.
