Калькулятор круток для гача-игр: считает, сколько валюты нужно зарабатывать в день, чтобы накопить нужное число круток к нужной дате.

## Что нового в 1.1.0

- **Три игры вместо одной.** К Genshin Impact (1 крутка = 160 примогемов) добавились вкладки **Arknights: Endfield** (1 крутка = 500 Oroberyl) и **Neverness to Everness** (1 крутка = 160 Annulith).
- **Всё подстроено под игру:** стоимость крутки, названия валюты и круток, пресеты цели и цвет интерфейса.
- **Память у каждой вкладки.** Дата, цель и накопления сохраняются отдельно для каждой игры и не сбрасываются при перезапуске.
- **Кнопка «⟲ Сбросить вкладку»** — вернуть значения текущей игры к начальным.

## Примечания

- Приложение не подписано сертификатом разработчика, поэтому при первом запуске Windows SmartScreen может показать предупреждение. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
- Портативная версия распаковывается во временную папку при запуске, поэтому первый запуск может занять несколько секунд.
- Значения сохраняются автоматически в localStorage. Если хранилище недоступно (например, приватный режим браузера), приложение работает как раньше — просто не запоминает введённое.
- Это неофициальный фанатский инструмент. Genshin Impact, Arknights: Endfield и Neverness to Everness — товарные знаки своих правообладателей.
